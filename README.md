Credit Card Application Analysis

 Project Overview

This project focuses on analyzing credit card application data to understand customer profiles and identify the factors that influence credit card approval decisions.

The dataset contains information about applicants, including their age, income, expenditure, credit history, home ownership, employment status, and other financial details.

The main objective of this project is to explore customer financial information, identify important patterns, and understand the characteristics of approved and rejected credit card applications using data analytics techniques.

 Dataset Information

- Dataset Name: Credit Card Applications
- File Format: CSV
- Total Records: 1,319
- Total Columns: 13
- Missing Values: No missing values found.

Dataset Features

The dataset contains the following columns:

Column| Description
rownames| Unique row identifier
card| Credit card approval status (Yes/No)
reports| Number of major derogatory reports
age| Age of the applicant
income| Applicant's income
share| Ratio of monthly credit card expenditure to yearly income
expenditure| Average monthly credit card expenditure
owner| Whether the applicant owns a home
selfemp| Whether the applicant is self-employed
dependents| Number of dependents
months| Months living at the current address
majorcards| Number of major credit cards held
active| Number of active credit accounts

Project Objectives

- Analyze credit card application data.
- Understand customer demographics and financial characteristics.
- Identify patterns in approved and rejected applications.
- Explore the relationship between income, expenditure, and credit card approval.
- Identify important factors that may influence approval decisions.
